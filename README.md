# CSCI566-F26

Official website for CSCI 566: Deep Learning and its Applications, USC Fall 2026.

Static site, no build step. GitHub Pages serves the repository root on `main`, matching
how `CSCI566-S25` and `CSCI699-S26` are set up.

## Files

| File | What it holds |
|---|---|
| `index.html` | Overview, prerequisites, logistics, assessment, guest lectures |
| `schedule.html` | The 14 Monday meetings and the assessment dates |
| `styles.css` | Copied from `CSCI699-S26`, unchanged |
| `images/` | `usc-banner.png`, `logo2.ico`, `300.png` |

`images/` deliberately excludes the six Spring 2025 TA photos that `CSCI566-S25` and
`CSCI699-S26` both carry. `CSCI699-S26` has no TAs at all, so those files are stale there
and worth deleting on the next pass through that repository.

## Publishing rule

Content flows one way and by hand: draft in the private `teaching-materials` repository,
then copy the student-facing result here. Nothing syncs automatically. The private
repository holds assignment solutions and prior-offering records, so an automatic sync
would eventually publish something it should not.

Student names, emails, and USC ID numbers do not belong in the private repository. TA
names and emails are appropriate on this public site once the roster is confirmed, which
is the reverse of the rule for the private repository and is deliberate.
